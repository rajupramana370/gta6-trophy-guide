Leonida Trophy Guide is an offline web guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: every trophy with its official name, description and grade, a guide in our own words that cites its sources (Exophase, PSNProfiles, PowerPyx, Push Square), a seven-stage roadmap to the platinum, the one confirmed missable trophy flagged, filters for story, missable, collectibles, activities and online trophies, a spoiler setting that hides story trophies until earned, and a checklist saved in the browser with export and import. It runs entirely from its own static files with no network, and it is honest about what cannot be verified yet — the game launched 19 November 2026, so unverified steps are marked as such instead of invented.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080
